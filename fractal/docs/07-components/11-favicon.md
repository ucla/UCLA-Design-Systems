A favicon, short for "favorite icon," is a small, typically square-shaped icon that represents a website or web page. It is displayed in various locations, such as the browser's address bar, tabs, bookmarks, and history lists.

#### When to use

You should use a favicon when you have a website or web page that you want to brand and make easily identifiable to users.

#### Best Practices

Only use the UCLA branded favicon. Avoid using the default favicon that comes with the framework you are using. Do not make a custom favicon.
