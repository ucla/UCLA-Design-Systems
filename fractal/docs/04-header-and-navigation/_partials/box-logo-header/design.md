The UCLA Box Logo header is a header and navigation component using the departments signature logo.

#### When to use

The Box Logo header can be used when the department has a signature, or logo lockup. This is offers a more branded approach that may be more suitable for schools like Nursing, Law, etc.

#### Anatomy

**Desktop**

![Box Header Logo Anatomy](/theme-assets/img/docs/navigation/box-logo-header-anatomy.svg)

**1. Blue Border (required)**

- Adds visual consistency with full bar version
- May container visual device or functional code to incorporate global emergency messaging

**2. Department Signature (required)**

- Text links to department home page

**3. Container (required)**

**4. UCLA Box Logo (required)**

- Logo links to ucla.edu

**5. Border (required)**
