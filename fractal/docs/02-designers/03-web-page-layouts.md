The Design Kit is made in Figma, a cloud-based design tool used for user interface design. Our styles and components have been combined to create pre-designed web page layout variations in Figma. These templates are offered for use as a starting point for designers to help provide guidance for common used pages. Components can be added or removed based on your needs.
